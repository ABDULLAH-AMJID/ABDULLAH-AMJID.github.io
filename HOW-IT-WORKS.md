# Portfolio — Kaise Chalta Hai

Ab tumhe naya project add karne ke liye **HTML chhoona hi nahi paray ga.**

```
portfolio/
├── index.html      ← website (cards ka hissa auto-generate hota hai)
├── projects.json   ← 👈 SIRF YE FILE EDIT KARNI HAI
├── build.py        ← projects.json → index.html
├── add.py          ← naya project add karne ka wizard
└── .github/workflows/portfolio.yml
```

---

## Naya project add karna — ek command

```bash
python add.py SpaceMedic-2
```

Repo ka naam do. Baaki ye khud kar leta hai:

1. **GitHub se data khud le aata hai** — language, topics, description, stars
2. Sirf woh cheezein poochta hai jo machine achhi nahi likh sakti
3. `projects.json` mein daal deta hai
4. `index.html` khud rebuild kar deta hai

Har sawaal par **default pehle se bhara hota hai** — pasand aaye to bas Enter dabao.

### Kya poochta hai

| Sawaal | Kya likhna hai |
|---|---|
| **Display name** | Site par jo naam dikhe. `phone-cam-pro` nahi — **PhoneCam Pro** |
| **Link** | GitHub URL (khud bhar deta hai) |
| **Category badge** | `Systems / C++`, `Real-time audio` — language se guess kar leta hai |
| **One-line subtitle** | Title ke neeche wali line |
| **Summary** | Kya karta hai. Ahem lafz `<strong>…</strong>` mein lapet do |
| **Technical detail** | **Sabse ahem** — kaise banaya, kya mushkil tha |
| **Tech tags** | Comma se alag. Topics se khud suggest karta hai |
| **Position** | `1` = sabse upar. Khali chhodo = sabse neeche |

> Summary aur detail mein **khali line dabane se** woh sawaal khatam ho jata hai (kyunke ye multi-line hain).

### Repo GitHub par nahi hai?

```bash
python add.py
```
Bina repo name ke chalao — sab manually pooch lega.

## Baaki commands

```bash
python add.py --list                # kitne projects hain, kis order mein
python add.py --top "SpaceMedic"    # sabse upar le jao
python add.py --move "Vortex" 3     # position 3 par bhejo
python add.py --edit "Vortex"       # dobara edit karo
python add.py --remove "ytflow"     # hata do

python build.py                     # projects.json se rebuild
python build.py --sync              # GitHub se stars/language refresh + rebuild
python build.py --check             # check karo ke sab sync mein hai
```

---

## ⚠️ Ek hi zaroori usool

`index.html` mein ye do lines hain:

```html
<!-- PROJECTS:START — generated by build.py, do not edit by hand -->
...
<!-- PROJECTS:END -->
```

**In ke darmiyan kuch bhi haath se mat likhna.** `build.py` har baar ise mita ke naya likhta hai — tumhari mehnat zaya ho jayegi.

Cards badalne hain? **`projects.json` badlo**, phir `python build.py`.

Baaki poori site — design, colors, skills, education, contact — **normal HTML hai**, jo marzi badlo.

---

## GitHub Action

`.github/workflows/portfolio.yml` har push par check karta hai ke `index.html` aur `projects.json` sync mein hain.

Agar tumne `projects.json` badla aur `build.py` chalana bhool gaye — **Action fail ho jayega** aur tumhe pata chal jayega. Warna website purani rehti aur tumhe khabar bhi na hoti.

## Rozana ka tareeqa

Naya project banaya → GitHub par push kiya → phir:

```bash
cd portfolio
python add.py MyNewProject
git add -A
git commit -m "feat: add MyNewProject to portfolio"
git push
```

GitHub Pages 1–2 minute mein khud update kar deta hai.

---

## Har mahine ek dafa

```bash
python build.py --sync
```

Ye GitHub se stars, language, aur archived status refresh karta hai. Ye data `projects.json` mein `_live` ke andar rehta hai — agar kabhi site par stars dikhane ka mann kare to pehle se maujood hoga.

---

## Poora automatic kyun nahi banaya

Main GitHub se saare repos khud kheench kar cards bana sakta tha. **Jaan bujh kar nahi banaya.**

Wajah: GitHub descriptions aisi hoti hain —
> *"Dockerised FastAPI media-fetching service with a web UI."*

Aur portfolio par is se kaam banta hai —
> *"Adaptive jitter buffer jo asli network jitter naapta hai aur buffer depth live tune karta hai, RTT monitoring ke saath."*

Doosri wali koi API nahi likh sakti. **Wohi cheez recruiter ko rokti hai.** Isliye system ne machine ka kaam (data laana, HTML banana, order sambhalna) automatic kar diya hai, aur insaan ka kaam (achhi baat likhna) tumhare paas chhoda hai.

## Ek chhoti si baat

Agar `sharp-pixel-magic` ka naam badal ke `pixel-lift` karo, to link bhi update karna:

```bash
python add.py --edit "Sharp Pixel"
```

Link wale sawaal par nayi URL daal dena. Ya `build.py --sync` chalao — purani URL 404 dikhaye gi to pata chal jayega.
